# CoffeeCRM — Frontend

React + TypeScript + Vite. Инструкция по запуску, переменные окружения и описание API — в [корневом README](../README.md).

```bash
npm install
cp .env.example .env   # VITE_API_URL — адрес бэкенда
npm run dev            # http://localhost:5173
npm run lint
npm run build
```
